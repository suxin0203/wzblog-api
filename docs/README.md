## 文档更新规则

1. 改口径（业务语义/时间语义/幂等/校验）→ 先改 [decisions.md](decisions.md)，再同步接口文档。
2. 改接口（路由/字段/错误码/SSE）→ 改 [api/接口对接文档.md](api/接口对接文档.md)；校验上限与业务码再改 [api/error-codes.md](api/error-codes.md)。
3. 改表结构 → 改 [03-数据库设计.md](03-数据库设计.md) 并同步迁移说明。
4. 新增文档必须在本页“权威文档”表登记；未登记的一律视为非权威。
5. 历史内容只归档不删除；归档文件仅允许顶部 ARCHIVED 注释，正文不改。
