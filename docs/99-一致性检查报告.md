## 3. 关键语义确认

| 主题 | 最终口径 |
|---|---|
| 认证 | Access 15 分钟、Refresh 14 天；刷新即轮换；旧 token 复用吊销整个 family；登出黑名单 `jti` |
| 角色 | `USER/EDITOR/ADMIN`；EDITOR 管内容/审核，ADMIN 全权；不再有 `is_root` |
| 文章 | `DRAFT/PUBLISHED/ARCHIVED` + `visibility` + `is_pinned` + `deleted_at`；发布后 slug 不变；恢复不重新发积分 |
| 积分 | 账本只追加；`idempotency_key` 唯一；日上限按 Asia/Shanghai；反转封顶余额；对账自动补 `ADMIN_ADJUST` |
| 订单 | `PENDING→APPROVED/REJECTED/CANCELLED`；`APPROVED→SHIPPED/CANCELLED`；`SHIPPED→COMPLETED`；条件更新，非法跳转 409 |
| 库存 | 条件更新 `stock >= qty`；`stock IS NULL` 表示不限量；不先查后写 |
| 评论 | 两级树；仅 APPROVED 公开；父删子留；敏感词替换 `*` 并待审 |
| 点赞 | `article_reactions` 唯一键；幂等设置/取消；计数经 M2 端口同事务；每日对账 |
| 文件 | 预签名直传 + 魔数/解码/像素/大小校验；`TEMP→ACTIVE→ORPHAN→DELETED`；DB 先标记再删对象 |
| AI | OpenAI 兼容端点；6 个只读工具；最多 2 轮；SSE 五事件；游客令牌 Redis；IP/用户/游客三维配额 |
| 通知 | 13 类型；`dedupe_key` 唯一；未读数 Redis；SSE 用 fetch + Authorization |
| 统计 | 业务日 Asia/Shanghai；阅读经 Redis 日计数 + `drainDailyViews`；其余按当日行数重算；UPSERT 幂等 |
| 审计 | M0 `AuditRecorder` 写；afterCommit 独立事务；失败告警不阻断业务；读侧二次脱敏 |
