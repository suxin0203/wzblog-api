# 07a · 验收用例矩阵（M0 平台 / M1 身份 / M2 内容 / M3 互动）

> 版本：1.0 ｜ 日期：2026-10-24 ｜ 契约版本：00 v1.6、04 v1.0
> 使用说明：本文件是 M0~M3 的验收基线，测试 Agent 直接按编号执行并回填结果；用例只引用 00/04/模块文档已冻结的路由、枚举与错误码。
> 编号规则：`TC-{模块}-{三位序号}`，如 `TC-M1-001`；端到端用 `E2E-{两位序号}`。
> 层级：`UNIT` 单元/组件，`WEB` 接口契约，`IT` 集成/事务/旁路，`CONC` 并发，`SEC` 权限与安全，`PERF` 性能与索引。
> 优先级：`P0` 阻断发布（主链路/安全/数据一致性），`P1` 版本内必修（边界/负向），`P2` 可延后但须登记。
> 执行环境：MySQL 8.0 + Redis 7 + TestClock（基线 2026-10-24T00:00:00Z）；业务日按 `Asia/Shanghai`；ID 断言均为字符串。
