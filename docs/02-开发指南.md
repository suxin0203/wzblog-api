```
│  ├─ common/   api/(Result、PageResult) error/(ErrorCode、异常、处理器) web/(TraceIdFilter、WebMvcConfig) util/

│  └─ modules/  identity | content | interaction | points | media | ai | admin | wechat
│     └─ content/(示例) api/(Controller、dto、vo、assembler) app/(AppService、Facade) domain/(实体、枚举、规则、events) infra/(Mapper、XML、Cache)
├─ src/main/resources   application*.yml · logback-spring.xml · db/migration/（V1__schema.sql、V2__seed.sql）
│                       mapper/（按模块分子目录，如 mapper/content/ArticleMapper.xml）· lua/（rate_limit_sliding_window.lua）
└─ src/test/java/com/wzblog   architecture/（ArchUnit） + modules/…（单元/切片/集成/并发）
```

| 层 | 职责 | 禁止 |
|---|---|---|
| `api` | 路由、参数校验、权限注解、DTO↔VO 转换 | 注入 `Mapper`、返回 `Entity`、写业务分支、开事务 |
| `app` | 用例编排、事务边界、跨模块调用、发事件 | 出现 `HttpServletRequest`、`ResponseEntity` |
| `domain` | 实体、枚举、领域规则、领域事件 | 依赖 Web、依赖 Mapper、依赖 Spring 上下文 |
| `infra` | Mapper 与 XML、缓存、对象存储、外部 API | 被 `domain` 反向依赖（实现 `domain` 端口除外） |

依赖只能自上而下：`api → app → domain`，`infra → domain`；`api` 不得 import `infra`。`shared` 只放跨模块技术能力，且不得 import `modules.**`。这两条写成 ArchUnit 测试，否则分支一多必然破窗。

## 5. 通用基础设施实现指南

> 以下为骨架与关键决策，属 M0 交付；业务模块不得各自实现一份。

### 5.1 Result 与 ErrorCode

响应壳固定 `{code, message, data, traceId}`；`code` 是**字符串**，成功固定 `OK`。
```java
public record Result<T>(String code, String message, T data, String traceId) {
    public static <T> Result<T> ok(T data) {
        return new Result<>(ErrorCode.OK.code(), "success", data, TraceId.current());
    }
    public static Result<Void> ok() { return ok(null); }
    public static <T> Result<T> fail(ErrorCode ec, String message, T data) {
        return new Result<>(ec.code(), message, data, TraceId.current());
    }
}

// 只示范 00 已出现的码；全量以 04 登记为准，一个码只在一处定义
public enum ErrorCode {
    OK("OK", 200, "success"),
    COMMON_VALIDATION_ERROR("COMMON_VALIDATION_ERROR", 400, "参数校验失败"),
    COMMON_NOT_FOUND("COMMON_NOT_FOUND", 404, "资源不存在"),
    COMMON_RATE_LIMITED("COMMON_RATE_LIMITED", 429, "请求过于频繁"),
    COMMON_INTERNAL_ERROR("COMMON_INTERNAL_ERROR", 500, "系统繁忙，请稍后重试"),
    AUTH_TOKEN_EXPIRED("AUTH_TOKEN_EXPIRED", 401, "登录状态已过期"),
    AUTH_FORBIDDEN("AUTH_FORBIDDEN", 403, "无权访问"),
    AUTH_ACCOUNT_DISABLED("AUTH_ACCOUNT_DISABLED", 403, "账号已停用");
    private final String code; private final int httpStatus; private final String defaultMessage;
    ErrorCode(String c, int s, String m) { this.code = c; this.httpStatus = s; this.defaultMessage = m; }
    public String code() { return code; }
    public int httpStatus() { return httpStatus; }
    public String defaultMessage() { return defaultMessage; }
}
```
枚举名与 `code()` 保持一致，便于 grep 对账；前端按前缀（`AUTH_`、`POINTS_` 等）分类。禁止模块内临时字符串异常。

### 5.2 BusinessException 与 GlobalExceptionHandler
```java
public class BusinessException extends RuntimeException {
    private final ErrorCode errorCode;
    private final transient Object data;   // 附加载荷，通常为 null
    public BusinessException(ErrorCode code) { this(code, code.defaultMessage(), null); }
    public BusinessException(ErrorCode code, String message, Object data) {
        super(message); this.errorCode = code; this.data = data;
    }
    public ErrorCode errorCode() { return errorCode; }
    public Object data() { return data; }
}

@RestControllerAdvice
public class GlobalExceptionHandler {
    @ExceptionHandler(BusinessException.class)
    public ResponseEntity<Result<Object>> onBusiness(BusinessException ex) {
        log.warn("business code={} traceId={} msg={}",
                ex.errorCode().code(), TraceId.current(), ex.getMessage());
        return ResponseEntity.status(ex.errorCode().httpStatus())
                .body(Result.fail(ex.errorCode(), ex.getMessage(), ex.data()));
    }

    @ExceptionHandler(MethodArgumentNotValidException.class)   // 字段错误全量聚合
    public ResponseEntity<Result<Object>> onInvalid(MethodArgumentNotValidException ex) {
        Map<String, String> errors = new LinkedHashMap<>();
        ex.getBindingResult().getFieldErrors()
                .forEach(e -> errors.putIfAbsent(e.getField(), e.getDefaultMessage()));
        return ResponseEntity.badRequest().body(Result.fail(
                ErrorCode.COMMON_VALIDATION_ERROR, "参数校验失败", Map.of("errors", errors)));
    }

    @ExceptionHandler({NoResourceFoundException.class, NoHandlerFoundException.class})
    public ResponseEntity<Result<Object>> onNotFound(Exception ex) {
        return ResponseEntity.status(404).body(Result.fail(ErrorCode.COMMON_NOT_FOUND, "资源不存在", null));
    }

    @ExceptionHandler(Exception.class)
    public ResponseEntity<Result<Object>> onUnknown(Exception ex) {
        log.error("unhandled traceId={}", TraceId.current(), ex);   // 堆栈只进日志
        return ResponseEntity.status(500).body(Result.fail(
                ErrorCode.COMMON_INTERNAL_ERROR, "系统繁忙，请稍后重试", null));
    }
}
```
- HTTP 表达传输/语义结果，`code` 表达业务细分原因；不再出现“HTTP 200 + 业务 400”。
- `ConstraintViolationException`（参数级校验）、`HttpMessageNotReadableException`、`MethodArgumentTypeMismatchException`（协议层格式错误）统一落 400 + `COMMON_VALIDATION_ERROR`，不另设码。
- 业务拒绝 `WARN`、不打堆栈；未知异常 `ERROR` + 完整堆栈；响应永不带堆栈、SQL、类名。
- **401/403 不经过** `@RestControllerAdvice`：异常发生在过滤器链，必须由 `AuthenticationEntryPoint` / `AccessDeniedHandler` 输出，且复用同一 `ObjectMapper` 与 `Result` 结构。429 需带 `Retry-After`。

### 5.3 TraceIdFilter
```java
@Component
@Order(Ordered.HIGHEST_PRECEDENCE)
public class TraceIdFilter extends OncePerRequestFilter {
    public static final String HEADER = "X-Trace-Id";
    public static final String MDC_KEY = "traceId";
    @Override
    protected void doFilterInternal(HttpServletRequest req, HttpServletResponse resp,
                                    FilterChain chain) throws ServletException, IOException {
        String traceId = req.getHeader(HEADER);
        if (!StringUtils.hasText(traceId) || !TraceId.isValid(traceId)) traceId = TraceId.generate();
        MDC.put(MDC_KEY, traceId);
        resp.setHeader(HEADER, traceId);   // 响应头与响应体由 MDC 保持同值
        try { chain.doFilter(req, resp); } finally { MDC.remove(MDC_KEY); }  // 线程复用必须清理
    }
}
```
- `Result` 通过 `TraceId.current()` 读 MDC，保证响应体与响应头同值。
- SSE 与线程池任务需手动传递上下文（`TaskDecorator` 包装 MDC），否则子线程丢 traceId。
- 日志 pattern 含 `%X{traceId}`；字段固定 `ts, level, traceId, userId, module, action, costMs`；禁止打印密码、token、openid、手机号明文。

### 5.4 Jackson 全局配置
```java
@Bean
Jackson2ObjectMapperBuilderCustomizer wzblogJackson() {
    SimpleModule bigintAsString = new SimpleModule("bigint-as-string");
    bigintAsString.addSerializer(Long.class, ToStringSerializer.instance);
    bigintAsString.addSerializer(Long.TYPE, ToStringSerializer.instance);
    return builder -> builder
            .timeZone(TimeZone.getTimeZone("UTC"))
            .featuresToDisable(SerializationFeature.WRITE_DATES_AS_TIMESTAMPS,
                    DeserializationFeature.FAIL_ON_UNKNOWN_PROPERTIES,
                    DeserializationFeature.ADJUST_DATES_TO_CONTEXT_TIME_ZONE)
            .modulesToInstall(bigintAsString);
}
```
- **BIGINT → 字符串**：全局把 `Long` 序列化为字符串，满足 00 §5.1 的 ID 契约。需要输出 JSON 数字的统计字段用 `int/Integer`；确需 `Long` 数值时局部 `@JsonFormat(shape = JsonFormat.Shape.NUMBER)` 覆盖。
- **UTC + ISO-8601**：VO 时间字段用 `Instant`（以 `Z` 结尾）；Entity 用 `LocalDateTime` 承接 `DATETIME(3)`，在 Assembler 里按 `ZoneOffset.UTC` 转换。
- 关闭 `FAIL_ON_UNKNOWN_PROPERTIES`：旧客户端多传字段不应报错。DTO 禁用 `java.util.Date`。

### 5.5 Spring Security 骨架
```java
@Configuration
@EnableWebSecurity
@EnableMethodSecurity
public class SecurityConfig {
    @Bean
    SecurityFilterChain chain(HttpSecurity http, JwtAuthenticationFilter jwtFilter,
                              AuthEntryPoint entryPoint, AccessDeniedHandlerImpl denied) throws Exception {
        return http.csrf(AbstractHttpConfigurer::disable).cors(Customizer.withDefaults())
            .formLogin(AbstractHttpConfigurer::disable).httpBasic(AbstractHttpConfigurer::disable)
            .sessionManagement(s -> s.sessionCreationPolicy(SessionCreationPolicy.STATELESS))
            .authorizeHttpRequests(a -> a
                .requestMatchers("/actuator/health", "/actuator/info").permitAll()
                .requestMatchers("/v3/api-docs/**", "/swagger-ui/**", "/swagger-ui.html").permitAll()
                .requestMatchers(HttpMethod.GET, "/api/v1/ping").permitAll()
                .requestMatchers("/api/v1/auth/**", "/api/v1/public/**").permitAll()  // 其余 PUBLIC/OPTIONAL 路由按 00 第 4 节逐条追加，禁止整体放行 /api/v1/**
                .anyRequest().authenticated())
            .exceptionHandling(e -> e.authenticationEntryPoint(entryPoint)    // 401 JSON
                    .accessDeniedHandler(denied))                             // 403 JSON
            .addFilterBefore(jwtFilter, UsernamePasswordAuthenticationFilter.class).build();
    }
    @Bean PasswordEncoder passwordEncoder() { return new BCryptPasswordEncoder(10); }
}
```
- **无状态**：不建 `HttpSession`，`SecurityContextRepository` 用 `NullSecurityContextRepository`。
- **JWT 过滤器占位**：`JwtAuthenticationFilter extends OncePerRequestFilter`，解析 `Authorization: Bearer`，校验签名/`exp`/`iss`/`aud`，回库确认 `status=ACTIVE`，再写入 `SecurityContextHolder`；解析失败**不抛异常**，交给 entry point 输出 401。
- **OPTIONAL 接口**：令牌缺失放行、存在则填充 principal，业务层 `currentUserId().orElse(null)` 判空，不写两套路由。
- 权限标记 → 实现（与 00 §3.2 一一对应）：

| 标记 | 实现 |
|---|---|
| `PUBLIC` / `OPTIONAL` | `permitAll()`；后者额外做可选 principal |
| `USER` | `authenticated()`（EDITOR/ADMIN 天然通过） |
| `EDITOR` | `@PreAuthorize("hasAnyRole('EDITOR','ADMIN')")` |
| `ADMIN` | `@PreAuthorize("hasRole('ADMIN')")` |
| `OWNER` | 不用注解；`app` 层按资源归属校验，ADMIN 可越过 |

统一 `SimpleGrantedAuthority("ROLE_" + role)`，只用 `hasRole/hasAnyRole`，不混用 `hasAuthority`。CORS 用来源白名单，不用 `*` 配 Cookie；Actuator 只暴露 `health/info`。

```java
MybatisPlusInterceptor mybatisPlusInterceptor() {
```

- 驼峰：`created_at ↔ createdAt`，SQL 不写别名；`@MapperScan("com.wzblog.modules.**.infra")`。
- 分页：后台用偏移分页，前台信息流/评论用游标 `(published_at, id)` 走索引，不套 `OFFSET`。
- **逻辑删除**按实体注解，不做全局配置（`points_ledger` 等表无软删列）：`@TableLogic(value = "null", delval = "now()") private LocalDateTime deletedAt;`。落地时用集成测试断言生成 `deleted_at IS NULL` 与 `SET deleted_at = now()`；若所用版本行为不同，改为 Mapper XML 手写条件。
- **枚举**：`@EnumValue` 标注落库值，DB 存字符串，禁止序号与魔法数字。
- **SQL 日志**：共享配置不开 `StdOutImpl`；本地用 `logging.level.com.wzblog.modules=debug`；另有 `SlowSqlInterceptor`（MyBatis `Interceptor`）记录 > 200ms 语句、耗时与脱敏参数。
- **`${}` 禁令**：一律 `#{}`；动态排序字段必须来自白名单枚举（`SortField.toColumn()`）。批量写入显式 `rewriteBatchedStatements=true`，单批 ≤ 500 行。

### 5.7 Redis 配置
- 序列化：key/hashKey 用 `StringRedisSerializer`，value/hashValue 用 `GenericJackson2JsonRedisSerializer`（复用 5.4 的 `ObjectMapper`，带类型信息）；Lua 限流只用 String 序列化，避免脚本里比对 JSON。
- 三套客户端分清：`StringRedisTemplate` 存计数/令牌/验证码；`RedisTemplate<String,Object>` 存结构体。
- **key 前缀**：`wzblog:{module}:{biz}:{id}`，全小写冒号分隔。花括号只是占位符，**实际 key 不含花括号**（Cluster 会把 `{}` 当 hash tag，误用导致分片倾斜）。例：`wzblog:identity:refresh:{jti}`、`wzblog:content:article:123`。
- key 常量集中在 `shared/cache/RedisKeys`；TTL 必须显式设置；删除用 `SCAN` + `UNLINK`，禁止 `KEYS *`。
- **Lua**：`src/main/resources/lua/rate_limit_sliding_window.lua`，用 `DefaultRedisScript` + `ClassPathResource` 加载为单例；调用时把所有 key 放进 `List`（集群安全），时间/窗口/阈值作参数传入，脚本内不读系统时间。
- Redis 只做缓存/限流/会话/计数（ADR-04），不得作为积分余额、订单状态、文章内容的唯一存储。

```java
@Bean
```

- 注解只在 DTO/VO 上写 `@Schema`、Controller 上写 `@Tag/@Operation`；公开接口用 `@SecurityRequirement(name = "")` 覆盖全局鉴权。

### 5.9 参数校验
```java
public interface Create {}   // 分组：新增
public interface Update {}   // 分组：全量更新
public record ArticleCreateDTO(
        @NotBlank(message = "标题不能为空") @Size(max = 150, message = "标题最多 150 字") String title,
        @Size(max = 300, message = "摘要最多 300 字") String summary,
        @NotNull(groups = Update.class) Long categoryId) {}
```
- `@RequestBody` 前加 `@Valid`；`@RequestParam`/`@PathVariable` 用类级 `@Validated`；分组用 `@Validated(Create.class)`。
- 提示语为面向用户的中文短句；所有字段错误聚合到 `data.errors`，不只报第一条。
- 业务规则（余额、状态机、slug 冲突）不进注解，由 `app`/`domain` 抛 `BusinessException`；DTO 白名单接收，禁止直接绑定 Entity。

### 5.10 统一时间/时区

| 层 | 规则 |
|---|---|
| JVM | `-Duser.timezone=UTC`（surefire 已配，IDEA 运行配置同样加） |
| MySQL | `connectionTimeZone=UTC&forceConnectionTimeZoneToSession=true`；容器 `TZ=UTC` |
| 列类型 | `DATETIME(3)` 存 UTC，不用 `TIMESTAMP`（避免隐式时区转换） |
| Entity / VO | Entity `LocalDateTime`（按 UTC 语义）；VO `Instant`，输出 `2026-10-24T04:00:00.000Z` |
| 入参 | ISO-8601 且必须带时区；缺时区视为非法，不默认补 `+08:00` |
| 业务日 | 日上限与统计日切按 `Asia/Shanghai`，时区取 `site_configs.stats.timezone` |

统一入口 `common/util/Times`：`nowUtc()`、`toInstant(LocalDateTime)`、`businessDay(Instant, ZoneId)`；业务代码禁止裸调 `LocalDateTime.now()`，便于测试注入。

## 7. 开发一个接口的标准流程（8 步）

以“某模块某个已冻结路由”为例，全程不改契约。

1. **读模块文档**：`docs/modules/Mx-*.md` 的路由、DTO、错误码、验收用例；路由与权限和 00 第 4 节逐字对齐。文档缺失先补文档。
2. **定 DTO/VO**：`api/dto`、`api/vo` 建 record，字段/必填/长度/枚举按模块文档；ID 用 `Long`，出参由全局 Jackson 转字符串。
3. **写 Mapper/XML**：`infra` 新增方法 + `resources/mapper/{module}/XxxMapper.xml`；只用 `#{}`，先确认命中哪个索引（见 03）。
4. **写 AppService 事务**：`@Transactional(rollbackFor = Exception.class)` 只标在 `app` 公开方法；状态变更用条件更新 `WHERE status = :from`，影响 0 行抛 409 对应码；副作用用 `@TransactionalEventListener(AFTER_COMMIT)`。
5. **写 Controller**：只做协议转换——`@Valid` 收参 → 调 AppService → Assembler 转 VO → `Result.ok(...)`；创建返回 201；权限注解与 00 的标记一致。
6. **错误码登记**：用到的码必须已在 04 登记、已在 `ErrorCode` 定义；缺码走变更流程，禁止就地新增字符串。
7. **测试**：domain 规则单测 + `@WebMvcTest`（校验/鉴权）+ `@SpringBootTest` + Testcontainers；覆盖 200/400/401/403/404/409 中受影响分支。
8. **EXPLAIN 与日志检查**：列表/统计 SQL 跑 `EXPLAIN`，确认走索引、无 `type=ALL`、无大表 `Using filesort`；确认日志有 traceId、无敏感字段；`mvn -q verify` + ArchUnit 通过。

## 8. 编码规范

| 主题 | 规则 |
|---|---|
| 命名 | 包全小写；类 `UpperCamel`；Controller/`*AppService`/`*Mapper`/`*DTO`/`*VO`/`*Assembler` 后缀固定；方法变量 `lowerCamel`；常量全大写下划线 |
| 布尔字段 | record 用 `enabled()`，避免 `isXxx` 与 getter 冲突 |
| 常量 | 业务常量集中在 `wzblog.*` 配置与 `site_configs`，禁止散落魔法值 |
| DTO/VO/Entity | 三者分离、禁止复用；Entity 只出现在 `domain`/`infra`/`app`，VO 只出现在 `api` |
| 映射 | 统一 MapStruct（`componentModel = "spring"`、`unmappedTargetPolicy = ERROR`），禁止长串手写 setter |
| Entity 出 Controller | 一律禁止；公开接口还要裁剪内部字段（手机号、openid、审计字段） |
| 事务 | 只在 `app` 层；不在 `api`/`infra` 开事务；不自调用事务方法；事务内不调 HTTP、不写大文件、不 sleep |
| SQL | 只用 `#{}`；`${}` 仅限白名单枚举拼列名；禁止 `select *` |
| 异常 | 业务拒绝抛 `BusinessException`；不吞异常、不 `catch` 后返回 `null`；不在 Controller `try/catch` |
| 日志 | 业务拒绝 `WARN`（无堆栈）、系统异常 `ERROR`（带堆栈）、关键动作 `INFO` 带 traceId 与业务主键；循环内不打日志；参数脱敏 |
| 注释 | 只写 **why**（为什么加锁、为什么这个上限、为什么绕过缓存），不写 what；公共类与端口接口写 Javadoc 并注明契约来源节号 |
| 空值与数值 | 集合返回空集合不返回 `null`；`Optional` 只用于返回值；积分/金额/计数用整数 |

## 9. Git 与分支

> 角色分工、共享文件仲裁、合并节奏与评审口径以 `docs/09-Agent协作手册.md` 为准，本节只给日常命令与最低要求。

当前目录还不是 Git 仓库，第一步是初始化（属 M0）：
```bash
git init
printf 'target/\n*.log\n.env\napplication-local.yml\n.idea/\n' > .gitignore
git add . && git commit -m "docs: 架构方案 v2 与全局契约基线"
```
- 分支：`main` 永远可编译、测试全绿；功能分支 `feat/m{编号}-{模块}`（如 `feat/m1-identity`）；修复 `fix/{简述}`；文档 `docs/{简述}`。
- **用 worktree 并行**，不要在同一目录切分支（`target/`、IDE 索引、未跟踪文件互相污染）：
```bash
git worktree add ../wzblog-m1 -b feat/m1-identity main
git worktree add ../wzblog-m2 -b feat/m2-content main
git worktree list
```
- 提交信息用 Conventional Commits：`type(scope): subject`，type ∈ `feat|fix|refactor|test|docs|chore|perf`，scope 用模块名；正文写“为什么”，不写“改了哪些文件”。
- 合并前 `rebase main`；冲突集中在共享文件时由架构 Agent 裁决，不回退契约。
- PR 模板要点：改了什么 / 为什么 / 如何验证（命令与结果）/ 是否触及契约（路由、表、枚举、错误码）/ 涉及查询的 `EXPLAIN` 结论 / 新增错误码是否已登记。

## 10. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 启动报端口占用 | 本机已有 MySQL/Redis，或上次容器未退 | `netstat -ano \| findstr :3306` 查 PID；`docker compose down` 后重启；或改映射端口 |
| MySQL 时间差 8 小时 | JVM 或连接时区未固定 | 连接串加 `connectionTimeZone=UTC&forceConnectionTimeZoneToSession=true`，JVM `-Duser.timezone=UTC`，容器 `TZ=UTC` |
| Flyway `checksum mismatch` | 改了已执行过的 `V*.sql` | 绝不改历史脚本，新增 `V{n+1}__{变更描述}.sql`；本地库直接删库重建，不用 `repair` 掩盖 |
| Flyway 报 database 不支持 | 缺 `flyway-mysql` | 补该依赖（版本由 BOM 管理），不手写版本 |
| 旧用户 BCrypt 校验失败 | 旧库为 `$2b$` 前缀 | `BCryptPasswordEncoder.matches` 兼容 `$2a/$2b/$2y`；新密码统一生成 `$2a$`，无需迁移，用集成测试固化 |
| Redis 连接拒绝 / `NOAUTH` | 容器未起或密码未注入 | `docker compose ps` 看健康；确认 `REDIS_PASSWORD` 已设且被 `spring.data.redis.password` 读到 |
| MinIO 预签名 403 | 用了内网 endpoint、region 不匹配、桶策略拒绝、时钟偏差 | 对外签发用公网 endpoint；本地 `pathStyleAccess=true`；region 与建桶一致；同步容器时间 |
| Windows 路径报错 / 乱码 | 反斜杠、非 ASCII 路径、编码 | 配置一律 `/`；`-Dfile.encoding=UTF-8`；仓库尽量放 ASCII 路径；`core.quotepath false` |
| Testcontainers 找不到 Docker | Docker Desktop 未启动 | 启动后 `docker info` 有输出；必要时设 `DOCKER_HOST=npipe:////./pipe/docker_engine` |
| Swagger 路径少了 `/api/v1` | 分组匹配串未带前缀 | 分组 `pathsToMatch` 写全路径，以 `/v3/api-docs` 输出为准 |
| 校验不生效 / 分页不生效 | 缺 `@Valid`/`@Validated`；较新 MyBatis-Plus 拆出分页解析器 | `@RequestBody @Valid Dto`，参数级校验用类级 `@Validated`；按所用版本核实是否需 `mybatis-plus-jsqlparser` |

## 11. 新手学习路径

**读文档顺序**（约 2 小时）：本文第 1、4 节 → 00 第 2、3、5、6 节 → 架构 3.1 / 5.1 / 8.9 / 9.5 → 03（只读自己模块的表与索引）→ 04（自己模块的错误码与公共 DTO）→ 对应 `docs/modules/Mx-*.md`（边写边查）。

**第一个接口怎么写**：

1. 先做 M0 的 `GET /api/v1/ping`：Controller → `Result.ok` → traceId → 200 → Swagger 可见，只验证管线。
2. 再做本模块的只读列表：练 DTO/VO、分页、索引与 `EXPLAIN`。
3. 最后做带事务的写接口：练 `@Transactional`、条件更新、错误码、`@TransactionalEventListener`。
4. 先写测试再改代码；先跑通 200，再补 400/401/403/409。

**验收方式**：

- Swagger：分组页 “Try it out”，确认请求体字段与 04 一致、响应壳含 traceId、401/403 返回 JSON 而非 HTML 登录页。
- curl 回归（带 body 的字段以 04 为准；验收时记录请求、状态码与 traceId，再用 traceId 定位整条链路）：
```bash
curl -i http://localhost:8080/api/v1/ping
curl -s -H "Authorization: Bearer $TOKEN" http://localhost:8080/api/v1/users/me | jq .
curl -s -o /dev/null -w '%{http_code}\n' http://localhost:8080/api/v1/users/me   # 期望 401
```
